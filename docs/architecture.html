Factory Inventory Management System

Vue 3 + FastAPI full-stack architecture — in-memory JSON data, no database

Tech Stack

Frontend

Port 3000
  • Vue 3 (Composition API)
  • Vite dev server
  • Vue Router
  • Axios HTTP client
  • i18n (English / Japanese)

Backend

Port 8001
  • Python FastAPI
  • Pydantic models
  • Uvicorn ASGI server
  • CORS (open in dev)
  • Auto-generated docs at /docs

Data Layer

In-memory JSON
  • 7 JSON data files
  • Loaded at startup via mock_data.py
  • 28 inventory items
  • 500+ orders (12 months)
  • No persistence across restarts

Testing

Backend only
  • pytest + FastAPI TestClient
  • 55 backend tests
  • 4 test files
  • No frontend tests configured

High-Level Architecture

Filter Data Flow

1

FilterBar.vue

User selects from 4 dropdowns: Period, Location, Category, Status

→
2

useFilters.js

Module-level singleton refs update. getCurrentFilters() maps UI names to API params

→
3

api.js

Builds URLSearchParams, skips 'all' values. Axios GET request sent

→
4

FastAPI

apply_filters() + filter_by_month() filter in-memory data sequentially

→
5

Response

Pydantic-validated JSON returned. View computed properties recalculate

Composables (Shared State)

useFiltersSingleton

Refs declared at module level so all components share one filter state. Exports selectedPeriod, selectedLocation, selectedCategory, selectedStatus, getCurrentFilters(), resetFilters(), and computed hasActiveFilters.

useI18nSingleton

English/Japanese support. Locale persisted in localStorage. Provides t(key), setLocale(), currentCurrency (USD/JPY), plus domain translators for product names, customers, and warehouses.

useAuthMock

Hardcoded user (John Doe / locale-aware). Provides currentUser, isAuthenticated, logout(), getInitials(). Includes 4 mock tasks with priority and status.
